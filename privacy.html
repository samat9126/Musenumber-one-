Privacy Policy

Last updated: November 11, 2026

This application ("the App") is a personal content tool operated by an individual creator ("the Operator"). The App uses the official TikTok Content Posting API to upload the Operator's own short videos into the Operator's own TikTok account as drafts.

What data the App accesses

  • TikTok account authorization data (access tokens) granted by the Operator through TikTok's official OAuth flow, only with the scopes the Operator approved (such as video.upload).
  • The video files the Operator chooses to upload as drafts.

How the data is used

  • Access tokens are used only to call the TikTok Content Posting API on the Operator's behalf, to upload draft videos.
  • Tokens are stored only on the Operator's own computer, are never sold, shared, or transferred to third parties, and are never used for advertising or profiling.
  • No data about any other person is collected. The App has no other users.

Revoking access and deleting data

The Operator can revoke the App's access at any time in the TikTok app settings (Settings and privacy → Security & permissions → Apps and services). Locally stored tokens can be deleted at any time by deleting the App's data folder.
